# Commit yesterday's flake update

Yesterday's `nix flake update` is staged in our flake-based NixOS repo, but
nobody committed it. Please commit it.

Run `bash setup.sh` first to prepare the repository. Write the commit message
to `commit-message.txt` and commit with `git commit -F commit-message.txt`.

There is no network here. `notes/update-summary.txt` is the saved output of the
update.
